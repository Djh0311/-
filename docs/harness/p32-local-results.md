# 查看当前交付结果

在项目根目录运行：

```sh
python3 -B -m collection_adapter.p32_result_entry
```

无需填写接口、字段、观察编号或导出参数。入口固定指向当前已交付的人民币元版本，不根据文件修改时间自动选择结果。它读取结果清单，检查列明的 11 个文件存在且权限符合要求，输出各表位置；不读取业务表正文、不重新导出、不启动采集。自动化读取状态可加 `--json`，成功退出码为 0，失败为 1。

当前交付清单记载 233 行商品/SKU/分类记录、155 个不同商品、200 个 SKU、19 个分类。233 行包含同商品跨分类关系，不能当作商品数。金额为人民币元，用户确认的适用范围和依据保存在结果中。

## 使用时保留的区别

- 空字符串、来源 null、来源未提供、未知和零不能互换；查看对应状态列，不把空单元格统一填零。
- 商品属性选项尚无确定的 SKU 对应关系，不能按位置或价格自行拼接。
- 库存负数、状态码、销量周期等没有完整解释依据，保留原字段和未知标记；金额单位确认不等于这些含义也确认。
- 优惠文案和价格数字不是个人可享资格的保证。地址相关配送适用条件、券引用的公共用途未确认。
- 图片下载、保存及引用导出已由用户排除。目标系统实际导入验证也不在当前任务范围。

当前覆盖仍为 PARTIAL。本次观察声明的成员集合已核对，但平台分页结束及未展示商品没有完整证据；入口显示文件可用不等于重新核对了业务正文，更不代表全店收齐或产品整体通过。

## 文件不可用时

入口会报告固定错误码和处理方法。目录或文件缺失时，核对原交付位置或从同一交付包备份恢复；不要混用不同版本。权限或链接不符合要求时，先核对文件来源及权限。清单损坏时恢复同包原件。入口不自动修权限、重写结果或重新采集。

本入口只解决当前既有结果的定位和读取说明。统一真实采集流程、完整产品验收仍未完成；既有业务数据验证见 [人民币元版本核对](reports/P31-confirmed-units-direct-check.json)，本地入口的验证见 [P32 本地入口报告](reports/P32-local-entry-validation.json)。
