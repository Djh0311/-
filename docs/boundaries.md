# 产品与安全边界

## 默认边界

项目只接受本地、合成、脱值、可完整校验的输入。没有新用户授权和新资格证据时，所有真实能力都视为关闭。

## 禁止输入与副作用

- 真实请求、响应、流量、Cookie、凭据、会话或私人消息；
- 历史 raw capture 正文或从中投影业务值；
- 网络访问、浏览器/微信 UI、系统代理、CA、keychain、管理员配置；
- 原始 payload 落盘、值哈希、自由键透传、敏感错误回显；
- 跨来源、跨时间或跨 observation 补值；
- 未冻结的目录、glob、可变输入集合或自动重试。

## 进入真实能力前必须重新裁决

至少需要：明确来源所有权与用途、冻结的 value-free shape、family/version、同观察绑定、隐私销毁规则、能力清单、失败停止行为、一次性输入锁和用户明确授权。任一项缺失，`LIVE_CAPTURE_LATCH` 与 `EXECUTION_LATCH` 继续保持 `CLOSED`。
